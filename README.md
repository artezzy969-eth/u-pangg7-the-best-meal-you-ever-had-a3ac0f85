# The Best Meal You Ever Had

[![make.fun](https://make.fun/badge/u-pangg7-the-best-meal-you-ever-had-a3ac0f85.svg)](https://make.fun/competitions/u-pangg7-the-best-meal-you-ever-had-a3ac0f85)

A Python program that writes one sentence — the best meal I ever had — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## Run

```sh
python3 main.py
```

## The sentence

One concrete memory: bubur ayam from a cart with no sign outside the
airport at five in the morning, eaten while saying goodbye to my brother —
the spoon still in my hand as he walked away.
